Aqui está o que foi mudado e por quê:

Banco de dados SQLite (classclean.db) com 3 tabelas:

TabelaO que guarda
usuariosid, nome, senha
turmasid, nome, pontos
tarefasid, turma_id (FK), titulo, descricao, concluida

Principais melhorias:

  • init_db() — cria as tabelas e insere os dados padrão automaticamente na primeira execução.
  • migrar_usuarios_json() — se você já tinha um usuarios.json, ele é importado para o banco e renomeado para .migrado automaticamente.
  • As tarefas agora usam id real do banco em vez de índice de lista, então concluir uma tarefa nunca apaga a tarefa errada.
  • Todos os dados sobrevivem ao reinício do servidor (antes, as turmas/tarefas eram perdidas por ficarem só em memória).

Para rodar:

bash
pip install flask
python app.py

O arquivo classclean.db é criado automaticamente na mesma pasta.
